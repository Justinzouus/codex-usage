# V1.0 统计口径

## 额度与本地用量

剩余额度和重置时间来自本机 Codex 的 `account/rateLimits/read`，不根据 Token 统计反推。历史统计只覆盖本机可读的 `sessions/` 与 `archived_sessions/`，不自动合并其他设备或仅云端的记录。

优先按逐响应用量记录统计，以 `response_id` 全局去重；旧格式使用累计 Token 的增量。同一轮已存在逐响应记录时，不重复累加镜像累计通知。总 Token = 输入 + 输出；缓存读取、缓存写入均属于输入，推理 Token 属于输出，不能重复相加。

## 项目、会话与执行

项目归属读取本地项目元数据；主会话和子 Agent 按可确认的执行关系归集。项目名称、短标题和目录均在本机处理。无法关联的记录仍计入总量，并标出缺口。会话每页 5 条，详情窗口按完成轮次分页；筛选不改变全局 KPI。

## API 等价估算

启动、后台每小时和大盘刷新时同步 OpenAI 官方公开价目表，新模型按精确 ID 补查模型页。Standard、Fast、Ultrafast、长上下文及 30m / 12h 缓存写入费率分别处理。不根据相似模型名猜价，也不把未知价格当作免费。网络或解析失败保留上次有效价格，并提示具体状态。

优先使用响应用量中的服务模式；缺少时，只读本机诊断日志中的会话 / 轮次 / 模型请求模式证据。请求模式不代表实际服务端处理回执；冲突或缺少证据的历史归入 Standard 并注明估算。实际 Token 不乘速度倍率。API 价格用于建立比较尺度，不代表套餐额度权重、credits 账单、历史实际支付价格或返现。

内置价格快照保留其核验日期，联网后按最新可确认价格回算；暂不含工具调用费、地区附加价和图像 / 音频独立费率。官方来源见应用内价格详情。

## 个人账期

V1.0 不内置作者的订阅费或扣款日。使用者在大盘“账期设置”填写月订阅费、每月扣款日（1–31）、时区与本账期额外额度金额。设置只保存在本机 `billing-settings.json`，macOS 权限为 0600；不是读取出的账户账单。

账期按所选时区的扣款日 00:00 估算，处理夏令时；不足指定日期的月份使用月末。未设置时不显示订阅比较结果。额外额度是手动输入的固定比较值，下个账期需自行更新。

参考差额 = 本账期 API 等价费用 − 自填订阅费 − 自填额外额度。负数表示低于比较基准；数据缺失、价格未知和模式估算均影响比较，不能当作实际收益。本机最早记录早于账期也不能证明整个账户记录完整。

## 周期、趋势与刷新

重置周期由历史周额度窗口和当前快照推定，最多保留最近 24 个周期；没有可靠窗口时显示空状态，不生成虚构周期。离线、切换账号和手动重置可能造成缺口。

趋势支持连续向左读取历史，按所选区间保持粒度，并可返回最新。统计依据已完成执行的完成时间归集，含可关联子 Agent。首次流式扫描，之后增量读取；过长行、不可读文件和关联缺口均单独计数。大盘可见时每分钟刷新，较旧的并发请求不会覆盖新筛选结果。
