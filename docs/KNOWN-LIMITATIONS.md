# V1.0 已知限制

- 仅提供 macOS Apple Silicon 预编译 DMG；最低构建要求 macOS 11，原生验收为 macOS 27。Intel 和 Windows 未发布预编译包。
- ad hoc 临时签名，未进行 Developer ID 签名或 Apple 公证；首次打开可能需要在系统设置中确认。
- 需要已安装并登录的本机 Codex；额度接口与本地历史格式变化可能影响兼容性。
- 只统计本机可读历史，API 等价费用为参考估算，不能视为账单或真实省款。
- 账期设置由使用者手填；额外额度是本账期固定比较值，需要自行维护，不与 OpenAI 账单同步。
- 额度卡支持中英文，大盘当前为中文；重置机会仅可查看。
